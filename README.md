# From-Anxiety-to-Calm
An interactive water ripple animation project using p5.js.


## Run the prototype

Use Code → Download ZIP and unzip the folder. Keep prototype.html and sketch.js together. Open prototype.html in a browser while connected to the internet so it can load p5.js 1.11.3. No installation is needed.

Move the pointer slowly, then quickly, and finally stop. The sketch changes ripple density, shape and colour in response to pointer speed. The animation logic is in sketch.js.
